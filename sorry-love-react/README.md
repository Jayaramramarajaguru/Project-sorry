# I'm Sorry, My Love 💖 (React + Vite)

A 5-page apology and love website with 3D CSS animations.

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build
```

## Deploy on Vercel
Import the GitHub repo. Vercel detects Vite automatically (build: `npm run build`, output: `dist`).

## Customize
- Quotes, promises and page names: `src/data.js`
- Apology letter text: `src/App.jsx` (the `Sorry` component)
- Colours and animations: `src/styles.css`
